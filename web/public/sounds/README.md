# Timer Sound Files

Place the following MP3 files in this directory. All are available free (no attribution required) from [Pixabay](https://pixabay.com/sound-effects/).

| Filename | Search term on Pixabay | Notes |
|---|---|---|
| `boxing-bell.mp3` | "boxing bell" | Short single-ring bell |
| `air-horn.mp3` | "air horn" or "airhorn" | Short blast |
| `whistle.mp3` | "whistle" or "referee whistle" | Short tweet |
| `chime.mp3` | "chime" or "bell chime" | Pleasant ding |
| `buzzer.mp3` | "buzzer" or "game buzzer" | Short buzz |

If a file is missing the app falls back to the synthesized version automatically.
